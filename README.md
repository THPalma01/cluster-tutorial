# ⚙️ Configuração de Cluster em Máquina Virtual

## 🧠 Descrição

Tutorial detalhado para criação e configuração de um cluster utilizando máquinas virtuais.

## 🎯 Objetivo

Explorar conceitos de infraestrutura, virtualização e comunicação entre sistemas.

## 🛠️ Tecnologias

* VirtualBox / VMware
* Linux

## ⚙️ Etapas realizadas

* Criação das máquinas virtuais
* Configuração de rede entre VMs
* Comunicação entre nós
* Testes de funcionamento

## 🧠 Conceitos aplicados

* Virtualização
* Redes
* Arquitetura distribuída
* Infraestrutura básica

## ▶️ Como executar

Seguir o passo a passo descrito no projeto.

## 📌 Observações

Projeto importante para demonstrar conhecimentos além do desenvolvimento tradicional.
